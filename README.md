# 월간 입법 진행현황 대시보드 템플릿

`Daily Brief`의 카드형 정보 구조를 참고해 법안 업무에 맞게 단순화한 정적 웹 템플릿입니다.

## 구성

- 월별 조회
- 소관기관·진행단계·검색어 필터
- 전월 대비 변동 표시
- 법안별 5단계 진행바
- 화면에서 현재 조회 결과를 Word 호환 `.doc` 파일로 다운로드
- 샘플 데이터는 `sample-bills.json`

## 실행

파일을 직접 더블클릭하면 브라우저 보안 때문에 JSON을 불러오지 못할 수 있습니다. 폴더에서 다음 명령을 실행합니다.

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

## 실제 API 연계 시 교체할 부분

1. `sample-bills.json`을 공식 API 수집 결과로 생성합니다.
2. 국회 진행단계는 국회 열린국회정보 API를 사용합니다.
3. 공포·시행 정보는 법제처 국가법령정보 공동활용 API를 사용합니다.
4. 정식 Word 양식이 제공되면 Python `python-docx` 생성기로 교체합니다.

이 파일의 예시 법안은 화면 검증용 샘플이며 실제 현황이 아닙니다.
