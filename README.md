# 월간 입법 진행현황 대시보드 템플릿

`Daily Brief`의 카드형 정보 구조를 참고해 법안 업무에 맞게 단순화한 정적 웹 템플릿입니다.

## 구성

- 월별 조회
- 소관기관·진행단계·검색어 필터
- 전월 대비 변동 표시
- 법안별 5단계 진행바
- 화면에서 현재 조회 결과를 업무보고형 Word 호환 `.doc` 파일로 다운로드
- Word 보고서의 주요내용은 불필요한 문구를 제거하고 현행 내용·문제점·개정 목적을 중심으로 최대 3개 항목·180자 이내로 자동 축약
- A4 가로 방향 5열 표, 반복 머리글, 조회조건·작성일·공식 원문 링크 포함
- 법안별 `비교 선택`으로 2~4개 법안의 발의자·소관·진행단계·핵심내용·고유 핵심어 비교
- `유사 법안 추천`으로 제목과 주요내용이 가까운 법안을 자동 선택해 비교
- 샘플 데이터는 `sample-bills.json`

## 실행

파일을 직접 더블클릭하면 브라우저 보안 때문에 JSON을 불러오지 못할 수 있습니다. 폴더에서 다음 명령을 실행합니다.

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

## 실제 API 연계 시 교체할 부분

1. `sample-bills.json`을 공식 API 수집 결과로 생성합니다.
2. 국회 진행단계는 국회 열린국회정보 API를 사용합니다.
3. 공포·시행 정보는 법제처 국가법령정보 공동활용 API를 사용합니다.
4. 별도의 정식 Word 서식 파일을 그대로 사용해야 할 경우 Python `python-docx` 생성기로 교체합니다.

## Word 보고서 요약 방식

현재 버전은 별도의 유료 AI API 없이 브라우저에서 원문의 핵심 문장을 추려 보고서용으로 축약합니다. 따라서 API 키를 GitHub에 등록할 필요가 없습니다. Word에서 보이는 실제 줄 수는 글꼴과 프로그램 버전에 따라 조금 달라질 수 있으나, 요약을 180자 이내로 제한하고 가장 넓은 표 열에 배치해 약 5줄 분량으로 표시되도록 구성했습니다.

## 자동 업데이트

GitHub Actions가 매일 오전 6시 37분(한국시간)에 실행됩니다. 공식 API 호출이 실패하면 최대 3회 재시도하며, 수집 결과가 0건이면 기존 정상 데이터를 보호하기 위해 저장하지 않습니다. 수동 실행은 GitHub의 `Actions` → `update-official-bills` → `Run workflow`에서 할 수 있습니다.

## 추적 법안 추가

`bill_keywords.yaml`에서 두 가지 방식으로 수집 대상을 추가할 수 있습니다.

- `bill_numbers`: 반드시 포함할 특정 의안번호
- `keywords`: 법안명에 해당 문구가 들어간 법안을 모두 포함

현재 의안번호 `2221507`을 직접 추적하고, `자본시장과 금융투자업` 관련 법안 전체를 `자본시장법`으로 분류하도록 설정되어 있습니다.

추가 검색 범위에는 건설산업기본법, 행정조사기본법, 상법, 중대재해처벌, 민사소송법, 조세특례제한법, 집단소송, 산업안전, 지속가능성·책임경영, 고용, 탄소중립, 상속세·증여세가 포함됩니다. 소관기관 필터에는 공정거래위원회, 중소벤처기업부, 기후에너지환경부, 고용노동부, 국토교통부가 항상 표시됩니다.

이 파일의 예시 법안은 화면 검증용 샘플이며 실제 현황이 아닙니다.
